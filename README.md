# Seconds-Rule-Tiered-ANN

This repository contains a runnable reference implementation for a tiered DRAM+SSD simulation around FAISS IVF-Flat,
including multiple caching/placement baselines and a seconds-rule policy.

## Quick start

```bash
bash scripts/run_all.sh configs/default.yaml
```

See `configs/default.yaml` for all parameters and `results/<run_id>/` for outputs.
